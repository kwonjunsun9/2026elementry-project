## 실습 #1

수업시간에 진행한 Git/GitHub 실습을 바탕으로 진행하면 됩니다. 
<br /> 수업시간에 한 내용을 완전히 똑같이 따라할 필요는 없으며, 자유롭게 파일을 만들고 수정하면서 Git 작업을 진행하면 됩니다. 

* GitHub Repository를 생성할 것
* Repository는 반드시 Public으로 설정할 것
* 파일을 생성하거나 수정하면서 commit을 최소 4개 이상 만들 것
* 생성한 commit을 모두 GitHub에 push할 것
* 과제 제출란에는 GitHub Repository 링크를 제출할 것
